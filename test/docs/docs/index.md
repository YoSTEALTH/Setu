# setu_classes

Setu's test extension, as a documentation site (`tools/check_docs.py`). Its API pages come from the module's
docstrings; this page and the [Guide](guide.md) are Markdown. `vec_norm2` links to its entry.

## Quick start

```python
from setu_classes import Vec, vec_norm2

print(vec_norm2(Vec(3, 4)))  # 25
```
